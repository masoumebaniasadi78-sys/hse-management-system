# 🏭 سامانه مدیریت HSE

**HSE Management System** - یک سامانه وب‌مبنا برای مدیریت ایرادات، اقدامات اصلاحی و حوادث ایمنی و بهداشت حرفه‌ای

## ✨ ویژگی‌ها

- 🔐 **سیستم ورود** - دو کاربر تست (Supervisor و Officer)
- 📊 **داشبورد** - نمایش آمار ایرادات، اقدامات و حوادث
- ➕ **ثبت ایراد جدید** - با تعیین واحد، سطح ریسک و شرح
- ✓ **مدیریت اقدامات اصلاحی** - تعریف اقدامات برای ایرادات
- ⚠️ **ثبت حوادث** - گزارش حوادث و شبه‌حوادث
- 📋 **لیست ایرادات** - مشاهده تمام ایرادات ثبت شده
- 💾 **ذخیره سازی محلی** - استفاده از LocalStorage برای ذخیره داده‌ها
- 📱 **طراحی واکنشی** - سازگار با تمام ابعاد صفحه
- 🌍 **پشتیبانی فارسی** - رابط کاربری کامل به زبان فارسی (RTL)

## 🚀 شروع سریع

### نحوه استفاده

1. فایل `index.html` را در مرورگر باز کنید
2. از اطلاعات ورود تست استفاده کنید:
   - **نام کاربری**: supervisor | **رمز عبور**: 1001
   - **نام کاربری**: officer1 | **رمز عبور**: 3001

## 📋 صفحات سیستم

### 1. صفحه ورود (Login)
- ورود کاربران با نام کاربری و رمز عبور
- نمایش اطلاعات کاربران تست

### 2. داشبورد (Dashboard)
- نمایش آمار:
  - کل ایرادات
  - ایرادات باز
  - اقدامات اصلاحی
  - حوادث ثبت شده
- دکمه‌های دسترسی سریع به قسمت‌های مختلف

### 3. ثبت ایراد (New Finding)
- انتخاب واحد (سالن رنگ، تزئینات، ...)
- تعیین سطح ریسک (A، B، C)
- وارد کردن عنوان و شرح ایراد
- ذخیره خودکار ID ایراد

### 4. لیست ایرادات (Findings List)
- مشاهده تمام ایرادات ثبت شده
- نمایش اطلاعات: ID، عنوان، واحد، تاریخ، سطح ریسک

### 5. اقدام اصلاحی (Corrective Action)
- ارتباط با شماره ایراد
- تعریف عنوان و شرح اقدام
- تعیین مهلت اصلاح

### 6. ثبت حادثه (Incident Report)
- انتخاب نوع: حادثه یا شبه‌حادثه
- تعیین شدت: خفیف، متوسط، شدید
- ثبت شرح تفصیلی

## 💾 ذخیره‌سازی داده‌ها

سیستم از **LocalStorage** استفاده می‌کند:
- `findings` - لیست ایرادات
- `actions` - لیست اقدامات
- `incidents` - لیست حوادث
- `currentUser` - اطلاعات کاربر فعال
